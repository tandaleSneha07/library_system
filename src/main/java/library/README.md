# Console-Based Library Management System

## Project Description

This is a Java console-based application that manages library operations using Object-Oriented Programming concepts.

## Features

- Add Book
- View Books
- Search Books
- Register Member
- View Members
- Borrow Book
- Return Book
- Library Statistics

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- File Handling
- Exception Handling

## Project Structure

- Book.java
- Member.java
- Library.java
- FileHandler.java
- Main.java

## How to Run

Compile:

```bash
javac library/*.java
```

Run:

```bash
java library.Main
```
